📦 Product Service

Product Management Dashboard

Add products, update price/stock, and search products with professional table views.

🔑

Service Credentials

REQUIRED

Add/Update/Delete and Add Category below require the same X-Service-Key value as this service's .env. It is remembered in this browser only.

➕

Add Product

POST

Enter product details in table format. The frontend will send the same data as JSON internally.

Product Name Category Image URL Price (incl. GST) Stock GST % HSN Option group Option label
📄

Bulk Import (CSV)

POST

Header row must include productName, productCategory, productPrice, productStock (productImageUrl, lowStockThreshold, gstRate, hsnCode, variantGroup and variantLabel are optional). One bad row does not stop the rest.

🧾

Product GST

PUT

Prices include GST; this sets how much of a product's price is tax on invoices, plus its HSN code. "Store default" uses the rate configured in OrderService.

🎛️

Product Options (variants)

PUT

Sizes, packs or colours of one thing. Make each option its own product (its own price, stock and GST), then give them the same group and a different label: the shop shows them as one product with an option picker. Put the option in the product name too (e.g. "Dove Shampoo - 340 ml"), since that is what a cart line and invoice show. Leave both boxes empty to turn a product back into an ordinary one.

🖼️

Upload Product Image

POST

Upload an actual image file for a product (JPEG/PNG/GIF/WEBP, up to 5MB) instead of pasting a URL - replaces that product's Image URL with the uploaded file.

🖼️

Product Image Gallery

POST

Additional photos beyond the single cover Image URL/upload above - shown in the storefront's product-details modal. Add by URL or file, view the gallery, or remove a photo by its image ID.
